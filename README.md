### This is a password policy extraction tool
This is designed for Chromebooks.

# HOW TO USE:
1. Open Chrome and go to chrome://net-export
2. In OPTIONS, enable "Include raw bytes"
3. Click "Start Logging to Disk"
4. Visit chrome://policy
5. Click "Reload policies"
6. Go back to chrome://net-export and click "Stop Logging"
7. Upload the resulting JSON file here
8. The tool will extract WiFi configs and display them in the table
